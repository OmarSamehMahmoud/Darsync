# Darsync — AI Lecture Studio

Darsync turns course PDFs, lecture notes, and textbooks into grounded,
teacher-led lessons with an interactive excerpt player, tutor narration, and
source-linked lesson history.

## What it does

- Admins organize study PDFs by course, subject, unit, and lesson topic.
- Uploads are copied to disk in bounded chunks (1 GiB per PDF by default).
- PDF pages are extracted and indexed one at a time. PaddleOCR handles scanned
  pages; SQLite FTS5 performs scoped retrieval over Arabic-normalized search
  text while preserving the original OCR text. No embeddings or vector
  database are used.
- Lessons split indexed pages into short, source-mapped excerpts within a
  bounded context. The player shows a crop of the original PDF excerpt beside
  the tutor video and a short spoken explanation for each segment; it does not
  display a page-by-page list or rewrite the book into generated lesson
  content. Arabic explanations use friendly Egyptian colloquial Arabic.
- Students can review lesson history, narration, sources, and print lessons.

## Run locally

The PaddleOCR 2.10 / PaddlePaddle 2.6.2 dependencies require Python 3.12 on
Windows. Create an environment with that interpreter:

```bat
py -3.12 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

Set the NVIDIA key in the shell that will run Darsync; do not put it in source
files or commit it:

```powershell
$env:NVIDIA_API_KEY = "<your-new-NVIDIA-key>"
```

`run.bat` uses `.venv\Scripts\python.exe` so OCR always runs under the same
Python 3.12 environment that received the dependencies. After switching
environments, restart the server and retry any PDF indexing jobs that failed.

Then start the server:

```bat
run.bat
```

Or run it directly:

```bat
".venv\Scripts\python.exe" -m uvicorn backend.main:app --host 0.0.0.0 --port 8900
```

Open **http://localhost:8900**. The default development admin is
`admin` / `admin123`; change it after the first login.

`NVIDIA_API_KEY` is required for lesson generation. Existing indexed pages are
normalized into the Arabic search index automatically at startup; OCR does not
need to be rerun. Do not launch the server with a different Python interpreter:
scanned PDFs require the PaddleOCR dependencies installed in `.venv`.

## Experimental free hosting (Render)

The root `render.yaml` and `Dockerfile` provide a starter deployment for a
Render free web service. Create a **private** Git repository containing this
project, connect it to Render, and create a Blueprint from `render.yaml`. Enter
a newly generated `NVIDIA_API_KEY` when Render prompts for it; do not put API
keys in the repository. `PHOTONX_JWT_SECRET` is generated by the Blueprint.
After the first deploy, sign in with the initial `admin` / `admin123` account
and change its password before sharing the site.

This is for testing only, not dependable hosting. Render's free service has
0.1 CPU and 512 MB RAM, spins down after 15 minutes without traffic, and has an
ephemeral filesystem. The SQLite database, uploaded PDFs, and OCR model cache
can all disappear on spin-down, restart, or redeploy. PaddleOCR may also exceed
the free service's memory or build limits. Do not use this deployment for
important files or as the only copy of your study materials. See Render's
[free instance limitations](https://render.com/docs/free).

## Configuration

| Variable | Default | Purpose |
|---|---|---|
| `NVIDIA_API_KEY` | unset | Required NVIDIA API credential |
| `PHOTONX_NVIDIA_API_URL` | `https://integrate.api.nvidia.com/v1/chat/completions` | NVIDIA-compatible endpoint |
| `PHOTONX_CHAT_MODEL` | `minimaxai/minimax-m3.1-flash` | Lesson and QA model |
| `PHOTONX_CHAT_MAX_TOKENS` | `16384` | Maximum generation tokens |
| `PHOTONX_MAX_UPLOAD_BYTES` | `1073741824` | Per-file PDF upload limit |
| `PHOTONX_OCR_LANGUAGE` | `ar` | PaddleOCR model language (`ar` or `en`) |
| `PHOTONX_QA_ENABLED` | `1` | Enable the QA Gate |
| `PHOTONX_QA_THRESHOLD` | `95` | Minimum grounding score (0–100) |
| `PHOTONX_QA_AUTO_REJECT` | `0` | Hide below-threshold direct answers; lessons enforce page-to-explanation mapping |
| `PHOTONX_JWT_SECRET` | development default | Set a strong secret in production |

PaddleOCR downloads its language models on first use and stores them under
`data/paddleocr/`. Keep enough free disk space for the uploaded PDF, SQLite
index, and OCR models.

## Tests

Run the local, provider-independent RAG tests:

```bat
python -m unittest test_rag_clauses test_nvidia_client -v
```

`test_e2e.py` exercises upload, indexing, PDF source preview, and NVIDIA
streaming against a running server, and therefore requires a valid
`NVIDIA_API_KEY`.

## Architecture

```
backend/
  main.py           FastAPI endpoints, upload jobs, page preview, SSE lessons
  rag.py            streaming PDF extraction, PaddleOCR, FTS retrieval, prompts
  nvidia_client.py  NVIDIA OpenAI-compatible chat-completions client
  qa.py             grounded-answer verification
  database.py       SQLite persistence, page index, FTS5 triggers
  config.py         environment-overridable settings
frontend/
  app.js            lesson player, source-page preview, history, admin tools
  index.html
  style.css
data/               SQLite database and PaddleOCR model cache
uploads/            uploaded source PDFs
```

The animated tutor video is served from `Darsync1/public/assets/tutor.mp4`
when that asset directory is present.

## API highlights

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/status` | NVIDIA API status |
| POST | `/api/files/upload` | Stream one or more PDFs to disk |
| POST | `/api/files/{id}/ingest` | Queue page extraction and indexing |
| POST | `/api/files/{id}/reindex` | Queue a replacement text index |
| GET | `/api/files/{id}/index-jobs/{job_id}` | Poll indexing progress |
| GET | `/api/files/{id}/pages/{page}/preview` | Render an authenticated PDF page or a normalized excerpt crop |
| POST | `/api/chats/{id}/stream` | Stream a grounded lesson via SSE |

Interactive API docs: **http://localhost:8900/docs**.
